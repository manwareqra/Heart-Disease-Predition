# Heart-Disease-Predition
ML pipeline comparing 5 algorithms (Logistic Regression, KNN, SVM) to predict heart disease risk using 10 patient biomarkers. Peak accuracy: 86.96%.

This project builds a predictive pipeline to evaluate cardiovascular disease risk based on clinical patient data. It trains, evaluates, and benchmarks multiple classification algorithms to find the most accurate model. 

Features:-
The model analyzes 10 key patient health biomarkers: 
Sex
ChestPainType
RestingBP
Cholesterol
FastingBS
RestingECG
MaxHR
ExerciseAngina
Oldpeak
ST_Slope

Tech Stack & Libraries:-
- Language: Python
- Environment: Google Colab
- Libraries: Scikit-Learn, Pandas, NumPy, Matplotlib/Seaborn

Model Performance:-
Five different algorithms were trained and evaluated. Logistic Regression delivered the highest performance metrics: 
1. Logistic Regression with 86.96% accuracy and 88.46% F1 score
2. K-Nearest Neighbors with 86.41% accuracy 88.15% F1 score
3. Support Vector Machine (SVM) with 84.78% accuracy 86.67% F1 score
4. Naive Bayes with 84.78% accuracy 86.14% F1 score
5. Decision Tree with 78.80% accuracy 80.40% F1 score
